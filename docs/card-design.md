# 卡牌设计

## 基础信息

`CardData.CardId` 使用整数 ID，用于运行时事件载荷、日志和配置检索标识。配置中心展示卡牌配置时会按 `CardId` 升序排列，ID 相同再按资源名排序。

## 卡牌类型

每张 `CardData` 都有且只能有一种卡牌类型，用于词条生效检索、流派分类和后续奖励筛选；默认类型为「通用」。

当前支持的类型：

| 类型 | 用途               |
|----|------------------|
| 通用 | 默认类型，用于不属于特定流派的卡牌 |
| 占卜 | 用于占卜相关词条、效果和流派检索 |
| 奥术 | 用于奥术相关词条、效果和流派检索 |

代码中可通过 `CardData.Type` 和 `CardData.IsType()` 判断卡牌类型。

## 卡牌效果

卡牌效果直接配置在 `CardData` 资产中，不再创建独立效果资产。

- `CardEffect` 是效果基类，具体效果继承它并实现 `Execute(BattleContext)`。
- `CardData` 使用 Odin 多态序列化显示「卡牌效果」列表，可在同一张卡牌内添加多个不同类型的效果。
- 当前内置效果包括 `DamageCardEffect`、`BoostSlotCardEffect`。
- 每张卡牌生效时拥有自己的 `BattleContext`，可在上下文中记录临时信息、注册临时事件，并在生效结束后自动清理。
- `DamageCardEffect` 可配置固定伤害，也可以开启随机范围，在下限和上限之间随机造成基础伤害。

### 生效时机

`CardEffect` 支持按时机执行：

| 时机 | 说明 |
|------|------|
| 放牌阶段 | 卡牌放入槽位后立即执行；撤回、换槽、手牌换槽或清槽时取消，换到新槽位后重新执行 |
| 出牌开始阶段 | 结束回合后先对全部槽位执行，适合增伤、注册后续触发条件等 |
| 出牌阶段 | 主效果阶段，默认用于造成伤害等直接结算效果 |
| 出牌结束阶段 | 等全部槽位的出牌阶段都执行完后，再按槽位顺序统一执行，可根据 `BattleContext.DamageDealtThisCard` 等出牌阶段结果触发额外效果 |

效果 Inspector 中会直接显示具体生效时机，不再显示“使用默认时机”。当前新增 `DamageCardEffect` 默认显示为出牌阶段，新增 `BoostSlotCardEffect` 默认显示为出牌开始阶段，之后仍可在卡牌配置中直接改成其他阶段。

## 卡牌显示

手牌、奖励选项、牌堆弹窗和出牌槽统一使用 `CardDisplayView` 刷新卡牌顶部类型、名称、费用、描述和图片。

- 顶部信息区：在卡牌顶上显示类型。
- 当前统一使用 `Full`：所有场景都显示完整卡牌信息，包含顶部类型、名称、费用、完整描述和图片。

各 UI 容器只负责交互和额外状态，不再分别拼接卡牌描述或直接刷新基础字段。卡槽背景由 `CardSlotView` 根据空槽或已放置卡牌状态控制。

## UI 层级

运行时 UI 通过 `UILayerManager` 在根 `Canvas` 下创建统一层级，不再给单张手牌单独挂 `Canvas` 调整排序。

层级从低到高为：

| 层级 | 用途 |
|------|------|
| `DragLayer` | 拖动中的手牌和槽位拖拽预览 |
| `PopupLayer` | 奖励选择、牌堆列表等普通弹窗 |
| `SystemLayer` | 战斗胜利/失败等系统级遮罩 |

手牌常态保留在手牌容器中；开始拖拽时临时移动到 `DragLayer`，放回手牌或对象池回收时再恢复父级。弹窗始终位于 `PopupLayer` 或 `SystemLayer`，因此不会被拖动中的手牌遮挡。

弹窗类 UI 由场景中的 `UIPopupManager` 常驻监听事件并按需加载：

- `BattleRewardPopup` 与 `CardListPopup` 通过 `AssetReferenceGameObject` 引用 Addressables 预制体，并动态实例化到 `PopupLayer`。
- 战斗胜利/失败结果面板由 `UIPopupManager` 运行时创建到 `SystemLayer`。
- 战斗主 HUD、手牌区、出牌槽、牌堆按钮等高频基础 UI 仍保留在场景中。
- 具体弹窗 View 只负责显示和交互，不直接监听打开弹窗的业务事件。

## 槽位结算

卡牌自身不再配置生效位置。卡牌放入任意槽位后都会执行放牌阶段效果；回合结算时，所有槽位中的卡牌都会按出牌开始、出牌、出牌结束三个阶段结算。

## 增伤效果

`BoostSlotCardEffect` 用于提高本轮伤害，可配置作用范围和提升方式，默认在出牌开始阶段生效。

作用范围支持：

| 范围 | 说明 |
|------|------|
| 指定槽位 | 按 1-5 号位任意组合生效，也可以直接选择任意槽位、奇数槽位或偶数槽位 |
| 自身 | 只影响这张增伤卡自身所在槽位 |
| 相邻牌 | 影响这张增伤卡左右相邻槽位，边缘槽位只影响存在的相邻槽位 |

当前支持的提升方式：

| 方式 | 说明 |
|------|------|
| 基础伤害增加 | 加到基础伤害区间，参与后续百分比和总增计算 |
| 伤害百分比增减 | 加到伤害增加区间，多个普通百分比增减先相加 |
| 伤害总增 | 加到伤害总增区间，每个总增都是独立乘区，多个总增连续相乘 |
| 固定值增加 | 加到固定值区间，在乘区计算完成后直接加到最终伤害 |

增伤数值可以开启“按所在槽位线性变化”。开启后，系统会以这张增伤卡所在槽位计算数值：递增表示 1 号槽使用基础数值，每向右一格增加一次“每槽变化”；递减表示 5 号槽使用基础数值，每向左一格增加一次“每槽变化”。在伤害总增模式下，基础数值就是基础倍率。

增伤只在本轮槽位结算期间存在。出牌开始阶段会先于全部出牌阶段统一执行，因此增伤卡放在 5 号槽也能影响本轮目标槽位；目标槽位的伤害在调用 `BattleContext.DealDamage()` 时应用增伤。

伤害公式为：

```text
最终伤害 = 基础伤害区间 * 伤害增加区间 * 伤害总增区间 + 固定值区间
```
